
# Overview
This mod adds apples as a mining result to the trees. Eating an apple heals the player by 16 health, and makes a nice crunchy Minecraft eating sound.

----------
# Features
- Apples can be eaten to heal the player by 16 health
- Each tree type has a different chance of dropping an apple
- Nostalgic Minecraft apple graphics and crunchy eating sounds
